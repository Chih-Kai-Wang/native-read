Mobile Browser Integration

在手機瀏覽器內直接啟用 NativeRead 懸浮球

除了直接使用本 PWA 閱讀 PDF 與文章外，您也可以將 NativeRead 安裝進 iOS Safari 或 Android 瀏覽器，在任何網站右下角喚出 NR 原版排版翻譯懸浮膠囊！

推薦 · iOS & Android 通用

1. 全平台 Userscript 腳本 (nativeread.user.js)

預設零干擾，僅在網頁右下角顯示極簡 NR 標籤；點擊即可展開翻譯膠囊、切換「譯文／原文／雙語」與管理白名單。

  • iOS Safari：安裝免費開源的 Stay 2 或 Userscripts App → 點擊下方按鈕即可一鍵匯入腳本。
  • Android：支援 Tampermonkey、狐猴瀏覽器 (Lemur)、Kiwi Browser、Firefox Nightly、Via 瀏覽器。
⚡ 安裝 Userscript (.user.js)
Android 完整擴充功能

2. Android 瀏覽器擴充功能包 (.zip)

包含完整 Chrome MV3 擴充功能與內建 PDF.js 原位閱讀器，適合支援載入擴充功能 ZIP 的 Android 瀏覽器。

  • 支援瀏覽器：狐猴瀏覽器 (Lemur Browser)、Kiwi Browser、Quetta、Edge Canary。
  • 安裝步驟：下載下方 ZIP 檔 → 打開瀏覽器的「擴充功能 (Extensions)」頁面 → 開啟「開發人員模式」→ 點選「載入已打包的 `.zip`」選擇該檔案即可。
📦 下載 Android 擴充功能安裝包 (.zip)
免裝任何 App · 隨點隨用

3. 免裝外掛書籤小工具 (Bookmarklet)

不想安裝任何擴充功能？只要將下方程式碼存成手機 Chrome 或 Safari 的「書籤」，在任何外文網站點一下該書籤，就會立即注入 NativeRead 翻譯懸浮球！
